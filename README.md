# Android TV Кинотеатр — скелет проекта

Стек: Kotlin + Jetpack Compose for TV + TorrServer (внешний, по указанному адресу) + TMDB API.

## Как запустить

1. Открой папку `androidtv-cinema` в Android Studio (Koala или новее).
2. Дай Gradle синхронизироваться — подтянет Compose for TV, Retrofit, Media3/ExoPlayer, Coil, DataStore.
3. Получи бесплатный ключ TMDB: https://www.themoviedb.org/settings/api
4. Подними TorrServer (https://github.com/YouROK/TorrServer) — можно локально на роутере/NAS/ПК в той же сети,
   либо на VPS. Проверь, что порт (обычно 8090) доступен с TV-устройства.
5. Запусти приложение на эмуляторе Android TV или физическом устройстве, зайди в **Настройки**
   и укажи:
   - адрес TorrServer, например `http://192.168.1.50:8090/`
   - TMDB API key
6. На главном экране появятся карусели (тренды/популярное/топ), в карточке фильма — описание,
   актёры и поле для magnet-ссылки → **Смотреть** отправит её в TorrServer и откроет плеер.

## Что уже готово

- `data/remote/TmdbApi.kt` — популярное/топ/тренды/поиск/детали+актёры
- `data/remote/TorrServerApi.kt` — добавление торрента, получение списка файлов, сборка stream-URL
- `data/settings/AppSettings.kt` — хранение адреса TorrServer и ключа TMDB (DataStore)
- Экраны: Home, Search, Details, Player (ExoPlayer), Settings
- Простая ручная DI (`CinemaApp.kt`) без Hilt — для скелета этого достаточно
